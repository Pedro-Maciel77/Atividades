# Business Model Canvas

> Escopo: trabalho do grupo · Fase 3: Modelagem do negócio · Data: não informada no documento original · Status: em revisão com base no arquivo enviado.

O relatório descreve o Altura como uma plataforma de matchmaking que conecta startups e investidores, buscando economizar tempo e ampliar o alcance das conexões.

## Blocos do Business Model Canvas

| Bloco | Conteúdo registrado |
|---|---|
| Segmentos de mercado | Startups em tração e investidores |
| Proposta de valor | Economia de tempo e mais alcance de conexões |
| Canais | Web e PWA |
| Relacionamento com clientes | Canal de notícias |
| Fontes de renda | Pagamento indireto: taxa de comissão quando o investimento é fechado |
| Estrutura de custos | Domínio próprio e servidor na nuvem, com infraestrutura em banco de dados |
| Recursos-chave | Base de dados e informações das startups e dos investidores |
| Atividades-chave | Algoritmo de compatibilidade funcional e segurança / LGPD |
| Parcerias-chave | Faculdades e polos, grupos de investidores e eventos |
