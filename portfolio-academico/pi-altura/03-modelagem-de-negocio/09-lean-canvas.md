# Lean Canvas

> Escopo: trabalho do grupo · Fase 3: Modelagem do negócio · Data: não informada no documento original · Status: documentado com base no relatório enviado.

O Lean Canvas do Altura foca no problema, na solução, nas métricas e na vantagem competitiva da plataforma de matchmaking.

## Blocos do Lean Canvas

| Bloco | Conteúdo registrado |
|---|---|
| Problema | Dificuldade de vínculo entre startups e mentores |
| Segmento de clientes | Fundadores, investidores e mentores |
| Solução | Plataforma de matchmaking |
| Proposta única de valor | Economia de tempo e mais alcance de conexões |
| Canais | Plataforma Web e PWA |
| Fluxos de receita | Taxa de comissão quando o investimento é fechado |
| Estrutura de custos | Domínio próprio e servidor na nuvem, com infraestrutura em banco de dados |
| Métricas-chave | Número de usuários e taxa de matches confirmados |
| Vantagem injusta | Algoritmo de compatibilidade que calcula a compatibilidade entre startup e investidor |
