# Código do MVP (pasta app/ do repositório NEXO)

> Escopo: trabalho do grupo · Fase 4: MVP · Data: não informada · Status: em andamento

## Resumo

MVP do Altura, uma plataforma web/PWA de matchmaking entre startups e investidores. A funcionalidade planejada é um algoritmo que calculará a **porcentagem de compatibilidade** entre startup e investidor. O algoritmo ainda não está implementado.

O código fica na pasta `app/` do repositório [Pedro-Maciel77/nexo](https://github.com/Pedro-Maciel77/nexo). O nome NEXO é o nome antigo do projeto, que hoje se chama Altura.

| Parte | Situação |
|-------|----------|
| Front-end (React 19 + TypeScript + Vite) | Interface pronta, com dados simulados |
| Back-end (Node.js) | Em desenvolvimento |
| Banco de dados | Em desenvolvimento |
| Algoritmo de compatibilidade | Ainda não implementado |
| LGPD | Planejamos seguir a lei |

## Conteúdo
