- Use os títulos descritivos para localizar a atividade.
- Consulte o [índice geral](../../INDEX.md) ou o [catálogo de metadados](../../catalogo.yml) para filtrar por tipo, UC, tags e escopo.

## Relações com outros conteúdos

O Radar do Altura aborda como estruturar informações para perfis e decisões. O cenário da clínica demonstra como transformar dados em conhecimento e ações. A atividade do SIOB trata da preservação e compartilhamento de conhecimento crítico.
