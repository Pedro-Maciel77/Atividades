# Radar de problemas informacionais — Projeto Altura

**Unidade Curricular:** Gestão da Informação  
**Escopo:** atividade em grupo do Projeto Integrador Altura  
**Arquivo original:** [Baixar/abrir o documento Word](originais/radar-problemas-informacionais-altura.docx)

## Objetivo

Identificar problemas informacionais no Altura e registrar evidências, impactos e possíveis causas.

## Problemas identificados

1. **Informações dos perfis ainda precisam ser mapeadas e estruturadas.** A plataforma depende de dados padronizados de startups e investidores para sustentar cadastro, perfis, busca e matchmaking.
2. **Critérios de compatibilidade ainda precisam ser definidos.** O projeto prevê critérios, score e ranking/recomendação, mas a atividade registra que esses elementos ainda precisam ser definidos e implementados.
3. **Indicadores e gestão das informações ainda precisam ser definidos.** O projeto prevê dashboards e relatórios, mas a estratégia de organização, qualidade e utilização das informações ainda precisa ser estruturada.

## Reflexão registrada na atividade

O problema considerado mais relevante para aprofundar é o mapeamento e a estruturação das informações dos perfis, pois esses dados sustentam o fluxo cadastro → perfil → busca → oportunidades → interesse/match.
