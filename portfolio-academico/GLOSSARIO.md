# Glossário

Termos do curso e do projeto, em ordem alfabética.

| Termo | Significado |
|-------|-------------|
| **Altura** | Nome atual do produto do PI: plataforma de matchmaking entre startups e investidores. Antes se chamava NEXO. |
| **Arquitetura da Informação** | Área que organiza e nomeia informação para que as pessoas a encontrem e entendam com facilidade. |
| **BMC (Business Model Canvas)** | Quadro de 9 blocos para desenhar um modelo de negócio. |
| **Catálogo** | Arquivo que reúne os metadados de todos os documentos (`catalogo.yml`). |
| **Classificação** | Agrupar conteúdos parecidos segundo um critério. Aqui: por UC e por fase do PI. |
| **Compatibilidade** | Percentual que o algoritmo do Altura calcula entre uma startup e um investidor. |
| **Customer Discovery** | Conversar com potenciais clientes para validar o problema antes de construir a solução. |
| **Encontrabilidade** | Facilidade de achar um conteúdo, navegando ou buscando. |
| **Escopo** | Indica se o trabalho é do `grupo` ou `individual`. |
| **Fase do PI** | Etapa do Projeto Integrador: pesquisa e empatia, customer discovery, modelagem do negócio ou MVP. |
| **Front matter** | Bloco YAML no começo do arquivo, entre linhas de três hífens, com os metadados do documento. |
| **JTBD (Jobs to Be Done)** | Método que busca entender o "trabalho" que a pessoa quer resolver ao usar um produto. |
| **Lean Canvas** | Variação do canvas focada em problema, solução, métricas e vantagem competitiva. |
| **LGPD** | Lei Geral de Proteção de Dados Pessoais (Lei 13.709/2018). |
| **Mapa de Empatia** | Quadro que organiza o que o público pensa, sente, vê, ouve, fala e faz, além de dores e ganhos. |
| **Matchmaking** | Aproximar duas partes compatíveis. No Altura, startups e investidores. |
| **Metadados** | Dados que descrevem outros dados. Aqui: título, tipo, UC, fase, data, status, tags. |
| **MVP** | Produto Mínimo Viável: versão enxuta do produto, feita para testar a ideia. |
| **Navegação** | Caminhos e links que levam a pessoa de um conteúdo a outro. |
| **NEXO** | Nome antigo do Altura. O repositório do código ainda usa esse nome. |
| **Persona** | Personagem que representa o usuário ideal do produto. No Altura, Marina Duarte. |
| **PI (Projeto Integrador)** | Projeto em grupo que junta o que foi aprendido nas várias UCs em um único produto. |
| **PWA** | Progressive Web App: site que funciona como aplicativo instalável. |
| **Relações entre conteúdos** | Ligações entre documentos que se completam ou dependem uns dos outros. |
| **Slug** | Versão do nome para arquivos e links: minúsculas, sem acento, com hífens. |
| **Status** | Situação do documento: `rascunho`, `em-andamento`, `em-revisao` ou `concluido`. |
| **Tag** | Palavra da taxonomia que marca o assunto, o método ou a tecnologia de um documento. |
| **Taxonomia** | Lista organizada de categorias e termos permitidos. |
| **UC (Unidade Curricular)** | Disciplina do curso, como FullStack ou Empreendedorismo e Plano de Negócios. |
| **Vocabulário controlado** | Lista fechada de termos, para o mesmo assunto não ter vários nomes. |
